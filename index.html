使用提醒

          
    
            
  • 坡頂（上邊坡）的載重通常會降低 Fs；坡趾（下邊坡）的載重通常會提高 Fs，也就是壓腳效果。
    • 
            
  • 坡趾的載重若可能被移走（停車、臨時堆料），不應依賴它提高安全係數，請分別計算有、無載重兩種情況，取較低的 Fs。
    • 
            
  • 填土本身有強度，滑動面也可能穿過它，請修改地表線並加入填土土層，不要用載重代表。
    • 
            
  • 道路車載等臨時載重，一般不計入地震慣性力；結構物等永久載重則應計入。
    •

方法原理與公式

          
本工具的計算核心係參考日本建設省土木研究所地すべり研究室的「動的計画法を用いた臨界すべり面解析法」（中村・久保田，1987，土木研究所資料第 2425 號，程式 CSSDP1）。以動態規劃搜尋任意形狀的臨界滑動面，並以簡易 Janbu 法計算安全係數。下文式號與原報告相同，方便對照。

          
Fs 可選簡易 Janbu 法、Spencer 法或 Morgenstern–Price 法計算，嚴密法的推導與驗證見第十節。

        


        

          
一、為什麼用動態規劃

          
臨界滑動面分析是在給定的地形、地層與土壤條件下，找出安全係數最小的滑動面。傳統做法先假設圓弧或對數螺旋，再移動圓心與半徑試算；多層地盤、地形起伏大時，真正的臨界面往往不是圓弧。動態規劃（Dynamic Programming，DP）由 Bellman（1957）提出，把問題拆成多個階段逐段求最佳解，可以在搜尋範圍內找出任意形狀的滑動面，不必事先假設形狀。

          
DP 依據最佳化原理：不論初始狀態與第一步如何選擇，其餘的決策對第一步造成的狀態而言必須是最佳的。多階段問題因此化為遞迴式。

          
fn=minG‾=min[G‾0+fn−1](1)

          
放到邊坡上，每一條垂直分割線是一個「階段」（stage），線上的候選點是「狀態」（state）。滑動面就是從第一條線走到最後一條線、每條線各選一點所連成的折線。

          
        


        

          
二、簡易 Janbu 法的安全係數

          
把滑動土體切成 n 個垂直切片。第 i 片受到自重 Wi、水平與垂直震度 kH、kV、滑動面上的正向力 Ni 與抵抗力 Ti，以及兩側的切片間水平力 E 與剪力 X。

          
          
切片的垂直與水平力平衡：

          
(1+kV)Wi+ΔXi=Tisinαi+Nicosαi(8)

          
ΔEi=−Ticosαi+Nisinαi+kHWi(9)

          
滑動土體兩端不受外力，X1 = Xn+1 = 0、E1 = En+1 = 0，所以 ΣΔXi = 0、ΣΔEi = 0（式 12、15、16）。滑動面上的抵抗力由 Mohr–Coulomb 破壞準則與安全係數定義：

          
Ti=ci′ℓi+(Ni−Uiℓi)tanφi′Fs(19)

          
由式 (8) 解出 Ni 代入式 (19)，再代入整體水平力平衡，並採用簡易 Janbu 法的假設 ΔXi = 0（切片間垂直剪力變化忽略不計，式 25），得到：

          
Fs=f0·∑Ai∑Bi(27)

          
Ai=ci′ℓicosαi+{(1+kV)Wi−Uiℓicosαi}tanφi′nαi(28)

          
Bi=(1+kV)Witanαi+kHWi(29)

          
nαi=cos2αi(1+tanαitanφi′Fs)(23)

          
Ai 是抵抗成分，Bi 是滑動成分。ℓicosαi 就是切片寬度 bi。Fs 同時出現在等號兩邊，需先假設初值再反覆計算到收斂。

          
f0 是補償 ΔXi = 0 假設的修正係數。原報告採用申・板垣（1983）的經驗式，L 為滑動面兩端點的直線距離，d 為平行此直線且與滑動面相切的直線到它的距離，也就是滑動面的最大垂直深度：

          
f0=(50d/L)0.03(30)

        


        

          
三、孔隙水壓

          
原報告以有效重量處理地下水，水位以下的土重改用水中單位重計算，式 (28) 因此改寫為：

          
Ai=ci′ℓicosαi+(Wi′+kVWi′)tanφi′nαi(31)

          
本工具直接由使用者畫的地下水位線計算切片底部的孔隙水壓，ui = γwhw，hw 為水位線到切片底部中點的鉛直距離。水位線以上的土以 γ 計重，以下以 γsat 計重，再以 (Wi − uibi) 代入式 (28)。水位線水平時兩種寫法完全相同。勾選「水位線傾斜修正」時改用 ui = γwhwcos²θ，θ 為水位線傾角。

        


        

          
四、Baker 的輔助泛函

          
DP 只能處理可以逐段相加的目標函數，而式 (27) 是兩個總和的比值，不能直接相加。Baker（1980）改以下列輔助泛函取代：

          
G‾=∑(Ai−Fs·Bi/f0)=A‾−FsB‾/f0(34)

          
以變分法比較兩者，在臨界滑動面 e 上：

          
δ(F‾s)e=f0δ(G‾)e(B‾)eδ2(F‾s)e=f0δ2(G‾)e(B‾)e(43)(44)

          
只要總滑動成分 B̄ > 0，G 的極小值條件（δG = 0、δ²G > 0）就是 Fs 的極小值條件。所以固定 Fs 後讓 G 最小，等於讓安全係數最小。G 可以逐段相加，DP 因此能夠處理。

        


        

          
五、DP 遞迴與計算流程

          
第一條分割線上所有候選點的累積值設為 0，之後逐線向前推進，每個點只保留累積值最小的前一點：

          
G1(K)=0,K=1…KK1(45)(48)

          
Gi+1(j)=minK=1…KKi{Gi(K)+DGi(K,j)}(47)

          
DGi=Ai−Fs0·Bi/f0(49)

          
DGi(K, j) 稱為「利得」，是第 i 條線的點 K 連到第 i+1 條線的點 j 這一段滑動面的貢獻。搜尋範圍延伸到地表以上，地表以上的線段利得為 0，滑動面的起點與終點因此成為解的一部分。最後一條線上累積值最小的點，再沿記錄的前一點回溯，就得到臨界滑動面：

          
Ts=minK=1…KKn+1[Gn+1(K)](46)

          
    
            
  1. 假設安全係數初值 λ（及修正係數 f0）。
    2. 
            
  2. 以式 (49) 計算所有候選線段的利得，用式 (47) 以 DP 求出使 G 最小的滑動面 yi。
    3. 
            
  3. 沿這個滑動面以簡易 Janbu 法反覆計算，得到它自己的 Fs。
    4. 
            
  4. 若 |Fs − λ| < ε 則結束；否則令 λ = Fs，回到步驟 2。
    5. 
          

          
本工具的「迭代紀錄」逐輪列出 λ 與該輪滑動面的 Fs，數值應逐輪下降並收斂。

        


        

          
六、滑動面形狀的限制條件

          
為了排除現實中不會出現的滑動面，原報告加入兩項限制。第一項要求滑動面為凹形（向上開口），避免中間凸起的異常形狀：

          
(d2ydx2)i≥0,i=1…n(50)

          
第二項要求 nαi > 0，避免坡趾附近反傾的切片算出負的抵抗力：

          
nαi>0⇒Fs>−tanαitanφi′(51)(52)

          
本工具對應的設定是「限制滑動面為凹形」。第二項改用較嚴格的常用準則 mα = cosα + sinα·tanφ′/F ≥ 0.2，只套用在反傾（α < 0）的切片。

          
凹形限制的判斷方式，以及網頁版的改良（坡度分級、節點容許誤差），可參考 凹形限制動畫說明 ↗，以三段動畫逐步說明。

        


        

          
七、補強構件（土釘與地錨）

          
每支構件在滑動面的交點，對滑動土體施加一個沿構件方向、指向坡內的拉力。可用拉力取下列最小值，再除以水平間距 Sh 換算為每公尺寬：

          
T=min(Tt,q·Le,Tf,P)ShPx=Tcosθ,Py=Tsinθ(R1)

          
Tt 為抗拉強度，q 為每公尺拉拔阻抗，Le 為穿出滑動面、位於穩定區的長度。土釘另受面版容量 Tf 限制；地錨只計錨碇段，錨碇段整段落在滑動體內時 Le = 0，並受設計錨力 P 限制。θ 為構件向下傾角。

          
把 Px、Py 加入原報告式 (8)(9) 的切片平衡後，依同樣步驟推導，主動法的安全係數為：

          
Fs=∑[c′b+((1+kV)W+Py−ub)tanφ′]/nα∑[((1+kV)W+Py)tanα+kHW]−∑Px(R2)

          
被動法則把 ΣPx 從分母移到分子，與土壤抵抗力一起除以 Fs。邊坡穩定時（Fs > 1），主動法算出的值一定比被動法高；一般預力地錨用主動法，靠變形才發揮的土釘用被動法，後者較保守。補強力只取決於每一段滑動面與構件的交點，G 仍可逐段相加，因此動態規劃可直接搜尋補強後的臨界滑動面，包括繞到構件後方的較深滑動面。

          
驗證案例：單一平面滑動塊體加一支地錨，在使用者指定的平面滑動面上，簡易 Janbu 法沒有切片間剪力的誤差，應與下列封閉解一致（主動法，L 為滑動面長，β 為傾角）：

          
Fs=c′L+(Wcosβ+Tsin(β+θ))tanφ′Wsinβ−Tcos(β+θ)(R3)

八、擋土牆（整體穩定）

          
擋土牆以多邊形表示，視為不可穿越、計入重量的結構物。滑動面的任何一段穿過牆體內部都視為不可行，因此搜尋只會找到從牆底下或牆後方通過的滑動面；沿牆底面或牆背滑動則允許。

          
切片重量由地表往下累加土重，再加上牆體造成的差值。牆體位於地表以下的部分，以牆的單位重取代原本的土重；突出地表的部分則直接加上牆重。對切片底部高程 zc：

          
W=b[W土(zc)+∑牆(γ牆h牆−W被取代的土)](R4)

          
這樣處理的是包含擋土牆在內的整體穩定，也就是滑動面從牆底或牆後通過時的安全係數。牆體本身沿底面滑動、傾倒、地基承載力等外部穩定，以及牆身結構強度，仍須依土壓力理論與相關規範另行檢核。

九、地表載重

          
均布載重 q 與線載重 P 都視為作用在切片頂面的垂直外力。每個切片承受的載重 Q 為 q 在切片寬度與載重範圍重疊段的積分（均布時即 q 乘以重疊長度，梯形分布時以兩端 q 的平均值乘以重疊長度），線載重則整個加在它所在的切片。只有滑動土體上方的切片會計入，Q 與土重一樣同時進入正向力與滑動力：

          
Fs=∑[c′b+((1+kV)W+Q+kVQ*−ub)tanφ′]/nα∑[((1+kV)W+Q+kVQ*)tanα+kH(W+Q*)](R5)

          
Q* 是勾選「計入地震慣性力」的載重。坡頂載重落在 α 為正的區段，增加的滑動力大於抵抗力，Fs 下降；坡趾載重落在 α 接近 0 或為負的區段，主要增加抵抗力，Fs 上升。動態規劃會自動找出載重影響下最危險的滑動面，包括繞到坡頂載重後方的滑動面，或從坡趾載重後方出露、避開壓腳效果的滑動面。

Fs=c′L+[(W+Q)cosβ−kHW′sinβ]tanφ′(W+Q)sinβ+kHW′cosβ(R6)

          
W′ 為受地震力作用的重量：載重計入地震慣性力時 W′ = W + Q，否則 W′ = W。

十、嚴密法：Spencer 法與 Morgenstern–Price 法

          
簡易 Janbu 法只滿足力平衡，並假設切片間剪力為零，因此需要經驗修正係數 f0。Spencer（1967）法與 Morgenstern–Price（1965）法同時滿足每個切片的力平衡與整體的力矩平衡，屬於嚴密法。兩者都假設切片間剪力 X 與正向力 E 成比例：

          
Xi=λf(xi)Ei(R1)

          
Spencer 法取 f(x) = 1，即所有切片間合力的傾角相同；Morgenstern–Price 法本工具採半正弦函數 f(x) = sin[π(x − xa)/(xb − xa)]，xa、xb 為滑動面兩端。計算採一般化極限平衡（GLE）的寫法：給定 Fs 與 λ，由滑動面一端逐片解水平與垂直力平衡，求出底部正向力 Ni 與切片間力 Ei：

          
Ei−1−Ei+Fx,i−Nisinαi+Sicosαi=0Xi−1−Xi+Fy,i+Nicosαi+Sisinαi=0Si=ci′ℓi+(Ni−uiℓi)tanφi′Fs(R2)

          
Fx,i、Fy,i 為自重、地震力、地表載重與補強力的合力，ℓi 為切片底部長度。滑動土體兩端沒有外力，最後一片須滿足 En = 0；再將各切片對自身底部中點的力矩相加，切片間力的作用高度互相抵消，得到整體力矩平衡條件：

          
∑i=1n−1[Ei(zi+1−zi)−Xi(xi+1−xi)]+∑i=1nMi=0,En=0(R3)

          
xi、zi 為第 i 片底部中點座標，Mi 為地震力（作用於切片重心）與補強力對底部中點的力矩。本工具以 Newton 法同時求解 Fs 與 λ，並排除 mα 過小的切片。補強力以主動法計入時直接作為外力；以被動法計入時，沿滑動面的分量與土壤抗剪力一起除以 Fs。

          
自動搜尋時，DP 仍以簡易 Janbu 法與 Baker 輔助泛函找出臨界滑動面，再以所選嚴密法計算 Fs。勾選「局部最佳化」時，再以樣式搜尋（pattern search）調整滑動面頂點高程與兩端位置，使嚴密法的 Fs 最小，過程中維持凹形限制。非圓弧滑動面經最佳化後，Fs 通常比最佳圓弧低 1–3%，Slide2 驗證手冊的非圓弧案例也有相同趨勢。

十二、滑動面控制點

          
地中監測（傾斜管、TDR、多段式伸縮計等）量到的剪動位置，以及地表的崩崖與坡趾隆起，是判斷實際滑動面最直接的證據。若讓程式自由搜尋，得到的臨界滑動面可能比實際淺或深，以它反算的強度或設計的對策也就失去依據。本工具可設定「控制點」與「出入口範圍」，要求搜尋的滑動面通過量測位置，再於此限制下找出最危險的滑動面。

          
控制點。每個控制點以位置 xc、地表下深度 d 與容許範圍 ±Δz 定義，控制高程 zc = zg(xc) − d。程式在 xc 插入一條分割線，並平移該線的節點，使其中一個節點恰好落在 zc；該線上只保留滿足下式的節點，其餘節點不可通過：

          
|zj−zc|≤Δz,zj<zg(xc)(C1)

          
動態規劃的每條路徑都必須在每條分割線上選一個節點，因此所有可行路徑都會通過控制點。限制只作用在狀態上，最佳性原理仍然成立，DP 得到的就是「通過所有控制點的滑動面」中 G 最小者，不需要另外試誤。Δz 可依剪動帶厚度或量測間距（例如 0.5 m）設定；Δz = 0 時滑動面恰好通過 zc。

          
出入口範圍。坡趾出口（隆起、湧水位置）與坡頂入口（崩崖、張力裂縫）可各限制一段 x 範圍。DP 由「尚未進入」轉為「進入土體」時，以該段滑動面與地表的交點 xe 判斷；由「土體內」轉為「離開」時，以交點 xx 判斷，交點不在範圍內的轉移一律不允許：

          
xt1≤xe≤xt2,xc1≤xx≤xc2(C2)

          
選用 Spencer 或 Morgenstern–Price 法並做局部最佳化時，最佳化過程同樣檢查每個控制點與出入口範圍，不會把滑動面移出限制。控制點對多情境檢核的每個情境都有效，計算結果與計算書會列出各控制點的檢核。

          
實務流程。(1) 依監測資料輸入各孔的剪動深度與容許範圍，並依現地調查設定崩崖與坡趾範圍；(2) 搜尋通過控制點的臨界滑動面，檢查形狀是否合理；(3) 按「以控制點建立指定滑動面」或複製臨界面為指定滑動面，以「反算分析」在 Fs = 1 下求滑動帶強度；(4) 以反算強度評估地錨、排水或抑止樁等對策。若自由搜尋與控制點搜尋的 Fs 相差很多，通常代表地層、水位或強度的設定與現地不符，宜回頭檢討模型。

十三、坡外積水與張力裂縫

          
坡外積水。地下水位線畫在地表以上的部分（河道、水庫、坡趾積水）視為積水。積水對滑動體有三項作用：切片頂面的水重 Qw；斜坡面上水壓的水平分量 Hw，推向坡內而抵抗滑動；滑動面上的孔隙水壓由積水面起算。hp 為切片處的積水深，Δzg 為切片頂面（地表）的高差：

          
Qw=γwhpb,Hw=γwhpΔzg,u=γw(zw−z)(W1)

          
三項合起來，相當於把積水面以下的土改用浮單位重 γ′ = γsat − γw 計算，因此完全淹沒的邊坡與用浮單位重計算的乾邊坡應得到相同的 Fs。這個關係只有在水壓合力於滑動體周邊閉合時才成立。DP 搜尋時，與地表相交的切片只計算地表以下的部分，使滑動面上與地表上的水壓水平分量互相抵銷；若以整片寬度計算，坡趾附近的深積水會讓少數切片的滑動力出現誤差，搜尋可能落到假性的淺層滑動面。這項處理也讓一般邊坡的 DP 計算值與同一滑動面的試算一致。

          
張力裂縫。c′ > 0 的土在坡頂附近處於主動狀態時，地表下一定深度內的側向應力為拉應力，土體容易開裂，裂縫內的土不提供抗剪強度。Rankine 理論的拉力區深度為下式，γ 取地下水位以上的單位重，各位置依該處地表的土層計算；也可直接指定裂縫深度（例如現地觀察值）：

          
zc=2c′γKa,Ka=tan2(45°−φ′/2)(W2)

          
程式在每條分割線上取最接近 zc 的節點作為裂縫節點。DP 在土體內的路徑到達裂縫節點時，可以選擇直接以鉛直裂縫離開土體。裂縫充水時，水壓合力 Pw 水平推向坡外，作用在裂縫底以上 zc/3，在 G 函數中當作滑動力：

          
Pw=12γwzc2,G←G−λPw(W3)

          
是否設裂縫、設在哪條分割線都由 DP 依 G 最小決定；若不設裂縫的 Fs 較小，結果就不含裂縫。嚴密法把 Pw 列入水平力平衡，並以作用點計入力矩平衡；局部最佳化時，滑動面末端沿裂縫底線移動，裂縫深度保持一致。指定滑動面試算與反算分析時，程式在滑動面低於裂縫底線的最靠坡頂處切斷滑動面。多情境檢核可分別設定各情境的裂縫是否充水，暴雨情境預設充水。

十四、分層水壓線與孔隙水壓比 ru

          
實際邊坡常有多個含水層，例如崩積層內的地下水位與下方受壓含水層的水頭不同，一條地下水位線無法同時代表兩者。本工具讓每個土層選擇自己的孔隙水壓來源：(1) 地下水位線，為預設的計算方式；(2) 水壓線，在「剖面」頁新增，可代表觀測井量到的水頭，高於地表的部分表示受壓水頭，不視為積水；(3) 孔隙水壓比 ru，即孔隙水壓與上覆土重的比值，常用於設計圖表與初步檢討；(4) 不計水壓。滑動面通過某層時，以該層的設定計算底部水壓：

          
u=γw(zpz(x)−z)cos2θ(P1)

          
u=ruσv,σv=∑iγihi(P2)

          
zpz 為水壓線高程，cos²θ 為選用的傾斜修正，σv 為滑動面以上土柱的重量（不含積水與擋土牆）。使用水壓線的土層在該線以下採飽和單位重，其餘土層以地下水位線區分 γ 與 γsat；坡外積水只由地下水位線決定。多情境檢核時，「水位上升」與「水位達地表」同樣作用在水壓線上，原本高於地表的受壓水頭維持不變；「無地下水」時各土層一律不計水壓；ru 不隨水位情境改變。
