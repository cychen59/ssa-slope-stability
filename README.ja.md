# SSA 斜面安定解析（Web 版）

[中文](README.md) | [English](README.en.md) | **日本語**

ブラウザ上で斜面断面、地層、地下水位を描き、**動的計画法（DP）** で任意形状の臨界すべり面を探索して、**簡易 Janbu 法**、**Spencer 法**、**Morgenstern–Price 法** のいずれかで最小安全率を計算します。インストール不要で、ページを開くだけで使えます。

**オンラインで使う：<https://cychen59.github.io/ssa-slope-stability/?lang=ja>**

## 主な機能

- **断面の作成**：図上で節点をドラッグ・追加・削除するか、Excel から座標を貼り付けて、地表線、地層境界、地下水位を編集します。
- **CSV による地形の取り込み**：1 本の線（x, z）または断面全体（x、地表、各地層の上面、地下水位）。UTF-8 と Big5 に対応します。
- **土質定数**：地層ごとに γ、γsat、c′、φ′ を入力し、任意の地層を基盤岩（すべり面が通過しない層）に設定できます。単位は kN/m³ と tf/m³、kPa と tf/m² を切り替えられます。
- **間隙水圧と斜面外の湛水**：地下水位から u = γw·hw で直接計算します。傾斜した地下水位の補正（cos²θ）も選べます。地下水位線を地表より上に描いた部分は湛水（河川、貯水池、のり尻の湛水）とみなし、水の重さと斜面上の水圧を考慮します。完全に水没した斜面は水中重量による計算と同じ結果になります。
- **地層別の水頭線と ru**：地層ごとに間隙水圧の与え方を選べます。地下水位線（既定）、断面に追加した水頭線（被圧帯水層の観測水頭など）、間隙水圧比 ru、水圧なしの四種類です。複数ケース照査の水位設定は水頭線にも適用されます。閉じた解と Fredlund and Krahn (1977) の ru = 0.25 の例で検証済みです（理論ページ第十四節）。
- **引張亀裂**：頭部に鉛直の引張亀裂を設けられます。深さは Rankine 式 2c′/(γ√Ka) または指定値で、亀裂に水を満たすこともできます（Pw = ½γw·zc²）。亀裂の位置は探索で決まり、複数ケース照査ではケースごとに亀裂の水を設定できます。閉じた解と ACADS 例題 1(b) で検証済みです（理論ページ第十三節）。
- **地震**：水平震度 kH と鉛直震度 kV による震度法解析。
- **鉄筋挿入工とグラウンドアンカー**：頭部位置、傾角、長さ、間隔、各種耐力（引張、引抜き、頭部・のり面工、設計アンカー力）を入力し、列でまとめて配置できます。補強力は各耐力の最小値とし、主働法または受働法で考慮します。補強の有無による Fs と臨界すべり面を並べて表示します。
- **抑止杭、マイクロパイル、ジオシンセティックス**：抑止杭は鋼管杭で、くさび杭または抑え杭を選べます。地すべり防止技術指針に従って必要抑止力を求め、曲げ応力、せん断応力、根入れ長、地盤の降伏を照査します（kh、β は道路橋示方書、抑え杭は Chang の式）。探索ではすべり面ごとに交点から杭の許容荷重を求め直すため、杭の下や前後を通るすべりも自動的に検討されます。マイクロパイルは軸力とせん断力を考慮します。ジオグリッドとジオテキスタイルは低減後の許容引張力と両側の引抜き抵抗で計算し、力の方向は水平またはすべり面方向を選べます。くさびの閉じた解と鋼管杭の計算例で検証済みです（理論ページ第十五節）。
- **地表荷重**：等分布、台形、線荷重に対応し、地震慣性力の考慮を荷重ごとに選べます。荷重なしの場合との比較も表示でき、図上で荷重の端点をドラッグできます。
- **擁壁**：パラメータ（つま先、底面標高、壁高、底幅、天端幅）または頂点座標で作成し、重量をもつ不透過の構造物として扱って、擁壁を含む全体安定を計算します。
- **指定すべり面の試算**：すべり面を 1 本描くか貼り付けて、その安全率だけを計算します。他のソフトや手計算との照合に使えます。
- **自動探索**：DP で非円弧の臨界すべり面を探索し、入口と出口の位置も自動で決まります。凹形の制約（勾配の分類で処理し、薄い弱層にも沿えます）と最小すべり深さを設定できます。凹形の制約の仕組みは[アニメーション解説](https://cychen59.github.io/ssa-slope-stability/concave-constraint.html?lang=ja)で見られます。
- **厳密法**：Spencer 法または Morgenstern–Price 法（半正弦 f(x)）を選べます。力とモーメントのつり合いを同時に満たし、探索後にすべり面を局所最適化できます。3 つの方法の結果を並べて表示し、解析解、Fredlund and Krahn (1977)、ACADS 標準問題で検証済みです（Web ページの理論第 10 節）。
- **すべり面の制御点**：孔内傾斜計や TDR で測定したせん断位置（x、地表からの深さ、許容 ±Δz）を入力し、末端出口と滑落崖の入口範囲も制限できます。探索するすべり面はこれらを必ず通り、結果に各点の照査が表示されます。制御点を通る指定すべり面をワンクリックで作成し、そのまま逆算できます。
- **逆算解析**：指定すべり面を実際の崩壊面とみなし、Fs = 1（または他の目標値）と仮定して、ある地層の c′ または φ′ を二分法で逆算します。同じ Fs となる c′–φ′ の組合せも表示し、ワンクリックで地層に適用できます。
- **複数ケースの照査**：「照査」タブで常時、豪雨時、地震時などのケースを設定し、それぞれの地下水位（断面の水位、Δh 上昇、地表面、なし）、震度、所要安全率を指定して一度に計算し、「ケース、Fs、所要値、判定」の一覧を出力します。所要安全率の既定値は水土保持技術規範第 73 条の永久のり面（常時 1.5、豪雨時 1.2、地震時 1.1）で、仮設の値や公路邊坡工程設計規範 表 4.6-1 をワンクリックで適用でき、直接変更もできます。
- **計算書の出力**：Word (.docx) のダウンロード、または印刷／PDF 保存ができます。入力データ、断面図と臨界すべり面、計算結果、スライス明細、各ケースの結果を含みます。
- **版番号と検証報告書**：ページ見出し、計算書、保存ファイルに版番号（現在 v2.8.0）を表示します。「説明」タブで検証報告書を実行すると、現在の版の計算核で全 112 項目の検証（閉じた解、Fredlund and Krahn、ACADS、湛水と亀裂、ru、補強材、鋼管杭の計算例など）をブラウザ上で再計算し、参考値、差、合否を一覧にして Word または PDF で出力できます。審査用のプログラム検証資料として使えます。版の履歴も「説明」タブにあります。
- **結果**：安全率 Fs と補正後の f0·Fs、すべり土塊の面積、入口と出口の座標、スライス明細、反復記録。いずれも CSV でコピーできます。
- **中国語・英語・日本語の表示**：ヘッダーの「中文／EN／日本語」で切り替えます。選択はブラウザに記憶され、アドレスに `?lang=ja` を付けると日本語表示で開きます。
- **保存と再開**：モデル全体（地形、地層、地下水位、パラメータ、設定）を JSON ファイルに保存し、後で読み込んで作業を続けられます。

## 使い方

1. <https://cychen59.github.io/ssa-slope-stability/?lang=ja> を開きます。既定の例題が読み込まれ、自動で計算されます。
2. **断面** タブで地表線、各地層の上面、地下水位を編集するか、CSV ファイルを取り込みます（[`examples/`](examples/) 参照）。
3. **土質** タブで各地層の γ、γsat、c′、φ′ を入力します。
4. **設定** タブで探索格子（モデルの大きさに応じた目安が表示されます）と震度を確認します。
5. **臨界すべり面を計算** を押します。
6. 作業を残すには、設定 → モデルファイルで **モデルを保存 (JSON)** を押します。次回は **モデルを読み込む…** で続きから作業できます。

オフラインで使う場合は、このリポジトリの `index.html` をダウンロードしてブラウザで開いてください。計算はすべてブラウザ内で行われ、データはどこにも送信されません。

### CSV の形式

断面全体（1 行目は列名でもかまいません。列名に「水」または water を含む列は地下水位として読み込みます。その x で値のない線は空欄にします）：

```csv
x,地表,風化岩上面,基盤岩上面,地下水位
0,10,6,2,10
20,10,6,,10.2
40,20,14,8,16
55,27,19,,22
80,28,20,12,24
```

1 本の線（選択中の線に取り込みます）：

```csv
x,z
0,10
20,10
40,20
55,27
80,28
```

## 手法の概要

計算の中核は、建設省土木研究所地すべり研究室による「動的計画法を用いた臨界すべり面解析法」（中村・久保田、1987）に基づいています。

- 簡易 Janbu 法：

  Fs = f0 · ΣAᵢ / ΣBᵢ

  Aᵢ = [c′ᵢbᵢ + {(1+kV)Wᵢ − uᵢbᵢ} tanφ′ᵢ] / nαᵢ

  Bᵢ = (1+kV)Wᵢ tanαᵢ + kH Wᵢ

  nαᵢ = cos²αᵢ (1 + tanαᵢ tanφ′ᵢ / Fs)

- Baker（1980）の補助汎関数 G = Σ(Aᵢ − λBᵢ)。ΣB > 0 のとき G の最小化は Fs の最小化と同じなので、DP で区間ごとに解けます：

  Gᵢ₊₁(j) = min over K { Gᵢ(K) + DGᵢ(K, j) }

- λ = Fs として収束するまで反復します。補正係数は既定で f0 = (50d/L)^0.03（申・板垣、1983）とし、Janbu の補正曲線も選べます。
- Spencer 法または Morgenstern–Price 法では、一般化極限平衡（GLE）の形で力とモーメントのつり合いを同時に解き、スライス間せん断力を X = λ f(x) E と仮定して、Newton 法で Fs と λ を求めます。DP のすべり面はパターンサーチで局所最適化できます。

導出、計算式、図の詳細は Web ページ下部の「理論と計算式」にあります。

## 適用範囲

- 二次元平面ひずみの極限平衡解析で、サクションは考慮しません。
- 間隙水圧は水位線（静水圧）または ru で算定し、浸透流解析は行いません。湛水には波浪や急速水位低下時の過剰間隙水圧は含みません。
- 簡易 Janbu 法はスライス間のせん断力を無視するため、補正前の Fs は通常安全側になります。
- 補強材は引張のみを受け持ち、曲げとせん断は無視します。
- 荷重は鉛直のみで、斜め荷重や急速載荷による過剰間隙水圧は含みません。
- 擁壁は全体安定のみを照査します。擁壁の滑動、転倒、支持力、部材強度は別途照査してください。
- 本ツールは解析を補助するもので、結果は参考値です。工学的判断と設計は、現地調査と関連基準に基づき、有資格の技術者の責任で行ってください。
